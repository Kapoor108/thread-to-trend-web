# Quick Start Guide

## Get Running in 3 Steps

### 1. Install Dependencies
```sh
npm install
```

### 2. Start Development Server
```sh
npm run dev
```

### 3. Open Your Browser
Navigate to: `http://localhost:8080`

---

## That's It! 🎉

Your ReVastra app is now running locally.

## What's Next?

- **Make changes**: Edit files in `src/` and see live updates
- **Add pages**: Create new pages in `src/pages/`
- **Style components**: Use Tailwind CSS classes
- **Build for production**: Run `npm run build`

## Common Commands

```sh
npm run dev          # Start dev server
npm run build        # Build for production
npm run preview      # Preview production build
npm run lint         # Check code quality
```
